## Overview

A reactive Java library providing common infrastructure components for building resilient microservices with Spring WebFlux, including:
- Comprehensive exception handling
- Router function utilities
- Command handler patterns
- Reactive utility classes

## Features

### 1. Exception Handling Framework
- **Custom Exceptions**:
  - `DomainException` - Base for business exceptions
  - `TechnicalException` - For infrastructure issues
  - `ValidationException` - Input validation failures
  - `NotFoundException` - Resource not found
